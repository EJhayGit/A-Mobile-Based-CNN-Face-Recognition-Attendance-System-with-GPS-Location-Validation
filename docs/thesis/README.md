## Source evidence and current code

The manuscript is an authored research record, not a fresh validation of this
repository. Its retained appendices include historical August snapshots,
test-count differences, and a Gantt status that predates later progress.
They were preserved rather than rewritten. The current public application's
one-installation authorization correction is later engineering work absent
from the study; physical two-phone verification remains outstanding.

The manuscript reports mixed biometric evidence and descriptive convenience
study results. See [model development](../model-development.md) and the
[model card](../model-card.md) for the original locked-threshold evidence and
later provisional-0.35 benchmarks. Workflow completion is not biometric
accuracy; a controlled offline trial is not a general reliability guarantee.
GPS provides location validation, with no formal spoof testing, and pose-based
liveness has no certified presentation-attack evaluation.

The manuscript's statement that model artifacts are excluded reflects its
publication plan. The authors separately directed this repository to retain
the existing inference-only MerLens ONNX. Its non-commercial research
restriction and unchanged public hash are documented in the model card.
No new model export, dataset, checkpoint, facial image, embedding, raw study
record, or experiment output is published with this manuscript.
